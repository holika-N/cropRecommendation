# Croptimal

**A python-based website that recommends what crops are suitable based on user input of soil quality**


## What it is
- A user input based website that aims to help farmers determine which crops are suitable for their soil quality to prevent potential depletion of soil, currently marketed for crops and farmers in Illinois**

## Features- 
- Determines top 3 suitable crops based off of nutrient contents such as soil pH, potassium levels, phophorous, magnesium, and carbon
- Allows users to see how suitable selected crops are for their soil quality
- Displays predicted market price for each crop based off of real world data

### Installation
1. Clone the repo
    'git clone https://github.com/holika-N/cropRecommendation'
2. Install dependencies
    'npm install'
3. Configure environment variables

## Instructions
- Simply input soil test results for required nutrients into each given spot
- Click "Find My Top Crops" and view 3 top crops
- If nutrient values out of range for most crops, website will display only the most suitable crop
- Users can also select which crop they would like to plant, ex. Pumpkins, to determine if it is suitable for their soil
